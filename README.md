Учёт телефонных разговоров

Лабораторная работа по ЯМП. Программа для учёта телефонных разговоров с возможностью ввода, сортировки, поиска и сохранения данных.

## Возможности

- Ввод данных о звонках (ФИО, номер, дата, время, тариф)
- Вывод в виде таблицы
- Сортировка по ФИО, дате или длительности
- Поиск звонков по номеру телефона
- Формирование перечня звонков по абонентам
- Запись и чтение из `.txt` файлов

## Структура

- `Structures.h` – структуры `MOBILE` и `TALK`
- `MyClass.h/cpp` – основной класс
- `MassA.h/cpp` – класс поиска
- `MassB.h/cpp` – класс перечня
- `Operators.h/cpp` – перегрузка операторов
- `SortVar.h/cpp` – функции для сортировки

## Используемые возможности C++

- Динамические массивы
- Конструкторы / деструкторы / копирование / присваивание
- Наследование классов
- Перегрузка операторов (`<<`, `>>`, `<`, `>`)
- Работа с файлами (`ifstream`, `ofstream`)
- Сортировка через функции сравнения

## Формат входного файла (`info.txt`)

Иванов И.И. +79123456789 31 12 2026 5 12 0 12 30
